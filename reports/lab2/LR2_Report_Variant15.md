# Лабораторная работа № 2
## Анализ и проектирование портала. Развёртывание программного обеспечения

**Вариант 15:** Университет. Центр АНОК

## 1. Цель работы

Спроектировать структуру учебного прототипа портала АНОК, определить состав данных и подготовить локальную базу SQLite.

## 2. Архитектура

Прототип состоит из трёх частей:

- веб-приложение Flask — маршрутизация и подготовка страниц;
- шаблоны Jinja2 — HTML-представление;
- SQLite — хранение связанных данных.

Пользователь открывает страницу в браузере. Flask получает данные из SQLite и передаёт их шаблону. Отдельный сервер базы данных не требуется.

## 3. Основные сущности

В базе хранятся роли, пользователи, подразделения, стандарты ФГОС, образовательные программы, учебные планы, дисциплины, служебные записки, подписи, отчёты проверки, компетенции, объявления и записи аудита.

Основные связи:

- образовательная программа связана со стандартом ФГОС и подразделением;
- учебный план связан с программой и пользователем, создавшим его;
- дисциплины связаны с учебным планом и реализующим подразделением;
- служебная записка связана с учебным планом и двумя подразделениями;
- записи согласования связаны с документом и пользователем.

## 5. Локальное развёртывание

Для запуска требуется Python 3. Зависимость Flask указана в `requirements.txt` и устанавливается командой:

```bash
python -m pip install -r requirements.txt
```

Команда запуска из каталога проекта:

```bash
python -m portal.app
```

После запуска приложение доступно по адресу `http://127.0.0.1:5000`.

Файл базы данных находится в `portal/anok_portal.db`. Схема исходных таблиц описана в `portal/schema.sql`.

## 6. Проверка результата

В прототипе доступны страницы сводной панели, учебных планов, проверки ФГОС, согласования, служебных записок, образовательных программ, стандартов, подразделений, компетенций, объявлений, аудита и карты сайта.

Работа с данными в текущей версии выполняется в режиме просмотра. Формы изменения данных и полноценная авторизация в эту учебную реализацию не включены.
