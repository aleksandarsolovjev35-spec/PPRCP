## 1. Цель работы

Разработать архитектурные диаграммы, структуру базы данных и развернуть выбранное программное обеспечение на PHP и MySQL/MariaDB.

## 2. Архитектура

Портал состоит из PHP-приложения, HTML/CSS-интерфейса и базы MySQL/MariaDB. Соединение с базой выполняется через PDO с подготовленными запросами.

## 3. База данных

В базе предусмотрены таблицы ролей, пользователей, подразделений, стандартов ФГОС, образовательных программ, учебных планов, дисциплин, служебных записок, согласований, компетенций, объявлений и аудита. Схема находится в `portal/database/schema.sql`, демонстрационные записи — в `portal/database/seed.sql`.

## 4. Развёртывание

1. Создать базу `anok_portal` в MySQL/MariaDB.
2. Выполнить `portal/database/schema.sql`.
3. Выполнить `portal/database/seed.sql`.
4. Указать переменные `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`.
5. Запустить PHP-сервер:

```bash
php -S 127.0.0.1:8000 -t portal
```

## 5. Примеры работы

В приложении доступны сводная панель, учебные планы, просмотр дисциплин по семестрам, стандарты ФГОС, программы, подразделения, компетенции, служебные записки, согласование, объявления и аудит.
