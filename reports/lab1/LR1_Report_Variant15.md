# Лабораторная работа № 1
## Выявление требований к порталу и выбор инструментального средства

**Вариант 15:** Университет. Центр аккредитации и независимой оценки качества (АНОК)

## 1. Предметная область

Центр АНОК проверяет учебные планы образовательных программ университета. Учебный план содержит дисциплины, семестры, трудоёмкость, часы, формы контроля и ответственные подразделения. Портал хранит эти сведения и предоставляет к ним доступ сотрудникам университета.

Основные процессы: подготовка плана, проверка в АНОК, согласование, утверждение и оформление служебной записки при изменении плана.

## 2. Акторы

| Актор | Назначение |
|---|---|
| Выпускающее подразделение | Подготавливает учебный план. |
| Реализующее подразделение | Рассматривает изменения дисциплин. |
| Эксперт АНОК | Проверяет план. |
| Руководитель АНОК | Рассматривает результаты экспертизы. |
| Проректор и ректор | Участвуют в согласовании и утверждении. |
| Секретарь Ученого совета | Фиксирует решение совета. |
| Студент или преподаватель | Просматривает утверждённые планы. |
| Администратор | Поддерживает справочники. |

## 3. Варианты использования

![Диаграмма вариантов использования](../../diagrams/use_case_diagram.png)

Основные варианты использования: просмотр учебного плана, проверка плана, просмотр маршрута согласования, работа со служебной запиской и просмотр справочников.

## 4. Требования к порталу

- хранение образовательных программ и учебных планов;
- хранение дисциплин, семестров, зачётных единиц, часов и форм контроля;
- просмотр учебного плана по семестрам;
- хранение стандартов ФГОС и контрольных параметров;
- отображение результата проверки и замечаний;
- отображение этапов согласования;
- хранение служебных записок и изменений «Было» / «Стало»;
- просмотр подразделений, компетенций и объявлений;
- журналирование событий;
- адаптивный веб-интерфейс;
- использование серверной СУБД MySQL или MariaDB.

## 5. Сравнение средств

| Средство | PHP | MySQL/MariaDB | Особенности |
|---|---|---|---|
| Drupal | Да | Да | Расширяемая CMS с готовыми модулями. |
| Joomla | Да | Да | CMS с развитой системой доступа. |
| Laravel | Да | Да | Фреймворк для разработки приложений. |

Для учебной реализации выбран PHP без обязательного фреймворка и PDO для работы с MySQL/MariaDB. Такой вариант требует меньше дополнительных компонентов и позволяет показать маршрутизацию, SQL-запросы и структуру портала непосредственно.

## Заключение

Определены предметная область, акторы, варианты использования и требования к порталу. Выбран стек PHP, MySQL/MariaDB и PDO, соответствующий условию лабораторной работы.
