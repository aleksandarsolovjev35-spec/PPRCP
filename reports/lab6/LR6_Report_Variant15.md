## 3. Детальное описание и примеры работы модулей

### 3.1. Модуль параметризованных запросов и безопасного доступа к данным
Подключение к базе данных осуществляется исключительно с использованием параметризованных подготовленных выражений (`Prepared Statements`), что исключает риск внедрения вредоносного SQL-кода:

```python
# Пример безопасного выполнения параметризованного запроса:
def get_semester_disciplines(curriculum_id: int, semester_num: int):
    conn = get_db()
    try:
        query = """
            SELECT cd.*, d.short_name AS dept_short
            FROM curriculum_disciplines cd
            LEFT JOIN departments d ON d.id = cd.implementing_department_id
            WHERE cd.curriculum_id = ? AND cd.semester_num = ?
            ORDER BY cd.id
        """
        return conn.execute(query, (curriculum_id, semester_num)).fetchall()
    finally:
        conn.close()
```

---

### 3.2. Модуль автоматизированной валидации по ФГОС ВО 3++
Модуль выполняет проверку соответствия параметров загруженного проекта УП нормативной базе стандарта:
1. **Баланс зачетных единиц:** $\sum \text{credits} = 240\text{ з.е.}$ (по 30 з.е. в каждом семестре 1–8).
2. **Экзаменационная нагрузка:** $\text{count}(\text{Exams}) \le 5$ в каждой промежуточной сессии.
3. **Объем практической подготовки:** $\sum \text{credits}(\text{Block 2}) \ge 12\text{ з.е.}$ (фактически 18 з.е.).
4. **Объем государственной итоговой аттестации:** $\sum \text{credits}(\text{Block 3}) \ge 6\text{ з.е.}$ (фактически 6 з.е. — ВКР и ГИА).

---

### 3.3. Модуль цифрового визирования и криптографических штампов (ЭЦП)
Модуль обеспечивает ведение цепочки согласования документа с фиксацией криптографического отпечатка SHA-256:
* Формирование хэша: `SHA-256(doc_id + user_id + timestamp + comment_salt)`.
* В интерфейсе отображаются статус визирования, дата, ФИО и верифицированный хэш.

---

### 3.4. Клиентский модуль мгновенного поиска и фильтрации (Live Table Filter)
Для быстрой работы с большими таблицами (журнал аудита, справочник дисциплин) подключен компактный JavaScript-компонент фильтрации:

```javascript
function filterTable(inputId, tableId) {
  const input = document.getElementById(inputId);
  const filter = input.value.toLowerCase();
  const table = document.getElementById(tableId);
  const trs = table.getElementsByTagName('tr');
  for (let i = 1; i < trs.length; i++) {
    const tds = trs[i].getElementsByTagName('td');
    let match = false;
    for (let j = 0; j < tds.length; j++) {
      if (tds[j].textContent.toLowerCase().indexOf(filter) > -1) {
        match = true;
        break;
      }
    }
    trs[i].style.display = match ? '' : 'none';
  }
}
```
