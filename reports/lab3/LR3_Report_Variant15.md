# Лабораторная работа № 3
## Создание шаблона дизайна портала

**Вариант 15:** Университет. Центр АНОК

## 1. Шаблон дизайна

Шаблон включает заголовочную часть с названием университета, боковое меню, основную область страницы и нижнюю часть страницы. Используются светлый фон рабочей области, тёмная навигация, синие ссылки и таблицы с разделителями.

Шрифты и отступы заданы в общем CSS блока `portal/index.php`. Интерфейс имеет адаптивное правило для небольших экранов.
