# Портал АНОК

Информационная система Центра аккредитации и независимой оценки качества образования (АНОК) для автоматизированной валидации учебных планов по ФГОС ВО 3++ и электронного согласования документов.

## Быстрый запуск (Python / встроенный SQLite)

База данных SQLite автоматически инициализируется из `database/schema.sql` и `database/seed.sql` при первом запуске:

```bash
python3 server.py
# или
python3 portal/server.py
```

Портал будет доступен по адресу `http://localhost:8000` (или `http://0.0.0.0:8000`).

## Запуск на PHP и MySQL/MariaDB

Создать базу и пользователя MySQL/MariaDB, затем выполнить:

```bash
mysql -u root -p -e "CREATE DATABASE anok_portal CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p anok_portal < database/schema.sql
mysql -u root -p anok_portal < database/seed.sql
```

Настроить переменные `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` и запустить встроенный сервер:

```bash
php -S 0.0.0.0:8000 -t portal
```

## Подключенные готовые модули и компоненты (ЛР № 6)

В портал интегрированы внешние open-source модули (подключаются из CDN, страницы
корректно отображаются и без загрузки скриптов — все данные рендерится сервером):

| Модуль | Назначение | Где используется |
|---|---|---|
| **Chart.js 4** | Диаграммы: структура блоков УП (doughnut), покрытие компетенций (radar), распределение часов по семестрам (stacked bar) | `?page=analytics` |
| **FullCalendar 6** | Календарный график регламентных процедур АНОК, этапов визирования и дедлайнов | `?page=calendar` |
| **DataTables 1.13** | Динамические таблицы: живой поиск, сортировка, пагинация дисциплин плана | `?page=plan` |
| **SheetJS (XLSX)** | Экспорт реестра дисциплин семестра в Excel | `?page=plan` |
| **jsPDF** | Формирование PDF-выгрузки учебного плана | `?page=plan` |
| **CryptoJS (SHA-256)** | Вычисление контрольных сумм структуры документа и верификация штампов ЭЦП | `?page=signatures` |
| **SweetAlert2** | Интерактивные диалоги подтверждения подписания документа | `?page=signatures` |
| **Toastify** | Toast-уведомления о статусах валидации, применения СЗ и дедлайнах | `?page=signatures` |
| **Diff2Html** | Визуальное side-by-side сравнение версий УП по служебным запискам | `?page=memos` |

Серверная часть (валидатор ФГОС, маршрутизация, параметризованные запросы,
журнал аудита) реализована нативно на Python 3 (`portal/server.py`) и PHP 8
(`portal/index.php`) — см. отчёт по ЛР № 6.
